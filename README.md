# Media Exporter for iPhone

Copy every photo and video off your iPhone to a Windows PC, safely: read-only, every file checked against the iPhone's own checksum, sorted into Year / Month folders, and it carries on by itself if the cable comes out. Free.

**Download the latest version:**
[Media-Exporter-for-iPhone-Setup.exe](https://github.com/warnz/media-exporter-for-iphone-releases/releases/latest/download/Media-Exporter-for-iPhone-Setup.exe)

Every version and what changed: [Releases](https://github.com/warnz/media-exporter-for-iphone-releases/releases) · More about the app: [warcal.dev/tools/media-exporter-for-iphone](https://warcal.dev/tools/media-exporter-for-iphone)

## Requirements

- Windows 10 (version 1809 or later) or Windows 11, 64-bit
- Apple's iPhone driver. Setup installs it for you if it's missing (Apple's free Apple Devices app from the Microsoft Store, no admin prompt). You never need to open it.

The installer isn't code-signed yet, so Windows SmartScreen asks once: choose **More info**, then **Run anyway**. It installs for your user only.
